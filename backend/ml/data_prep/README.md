# Dataset preparation scripts

These scripts clean and normalize six public hate speech datasets (Davidson,
Jigsaw, HateSpeech18, ToxiGen, TweetEval, and Civil Comments) into a common
format for training.

The code in this folder is MIT-licensed along with the rest of the repo, but
the datasets themselves carry their own separate licenses set by their
original publishers. If you redistribute the cleaned CSVs (not just the code
that produces them), check each dataset's original license/terms of use
before doing so.
